# 🦊 Fox AI

Отдельное приложение-помощник в том же стиле, что и **Fox Browser**: песочно-бежевая палитра
«песок и кофе», геометрическая лиса и официальный шрифт **Google Sans**.

## Что умеет

- 💬 **Отвечает на любые вопросы**: объясняет, советует, пишет тексты, переводит, помогает с учёбой.
  Работает бесплатно и без ключа (через открытый сервис Pollinations, не чаще одного ответа в 45 секунд —
  при лимите лиса сама подождёт и ответит). В меню можно подключить свой OpenAI-совместимый сервер с ключом.
- 🧮 **Сам решает математику — прямо на телефоне, мгновенно и без интернета**:
  - выражения: `2+2*2`, `(12,5 + 7,5) × 4`, `корень из 16`, `2^10`, `sin(pi/2)`;
  - уравнения с x: линейные и квадратные — точно и по шагам (с дискриминантом),
    любые другие (`x^3 = 27`, `2^x = 8`) — приближённо, численным методом;
  - проценты: `15% от 2400`.
- 🌗 Темы «Песок», «Кофе» и «Авто».
- 💾 История чата сохраняется; долгое нажатие на сообщение — копировать.

## Скачать

Готовый APK для Android после каждой сборки лежит здесь:
**https://github.com/ISOFT16/my-first-app0-/releases/download/latest/FoxAI.apk**

## Сборка на своём компьютере

```bash
dart run tool/setup.dart   # создаёт android/, ios/, windows/ и иконку приложения
flutter pub get
flutter run
```

## Структура

```
lib/
  main.dart             — запуск приложения
  chat_screen.dart      — экран чата
  settings_drawer.dart  — боковое меню: тема, сервер ИИ, новый чат
  fox_ai.dart           — подключение к ИИ (бесплатный сервер или свой)
  fox_math.dart         — встроенный решатель примеров и уравнений
  app_state.dart        — настройки и история
  theme.dart            — палитра «песок и кофе»
  fox_logo.dart         — логотип-лиса
assets/                 — иконка и шрифт Google Sans (SIL OFL)
```
